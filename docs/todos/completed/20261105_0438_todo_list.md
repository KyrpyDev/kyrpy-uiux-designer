## 2. Orchestration Plan (`@kyrpy-gru` -> `@kyrpy-dev-team` -> `@kyrpy-testusers-team`)

- [x] **Task 1: Backend SVG Folder & Font Import Engine (`SvgImportService`, `design-routes.js`)**
  - Extended `src/application/svg-import-service.js` to support importing into any current library type (`path`, `icon`, `button`, `element`) with `projectId`, `visibility` (`public` | `project`), `category`, and `actor` / `creatorId`:
    1. **Single SVG Import (`import`)**: Supports `as = 'path' | 'icon' | 'button' | 'element'`.
    2. **SVG Folder Batch Import (`importFolder`)**:
       - Browser folder upload (`files: [{ name, svg }]`)
       - Server/workspace directory scan (`folderPath`) for `.svg` files
       - Workspace folder discovery (`listSuggestedFolders`)
    3. **Font Import (`importFont`)**:
       - **SVG Font (`<font>` / `<glyph unicode="..." glyph-name="..." d="..."/>`)**: Extracts `<glyph>` paths, flips Cartesian font Y-coordinates into standard top-down 24×24 SVG coordinates using `parsePath` / `serializePath`, and imports each glyph into the current library (`path`, `icon`, `button`, or `element`).
       - **TrueType / WOFF Binary Font (`.ttf`, `.otf`, `.woff` base64 or file path)**: Zero-dependency SFNT/WOFF binary parser (`head`, `maxp`, `loca`, `glyf`, `post`) that extracts TrueType glyph quadratic Bézier contours into editable 24×24 SVG `<path>` nodes.
       - **Font Character / Symbol Glyph Set (`chars` / `glyphs` / `preset`)**: Imports customizable character or symbol sets into the current library.
  - Wired routes in `src/interfaces/http/controllers/design-routes.js`:
    - `GET /api/import/folders`
    - `POST /api/import/svg`
    - `POST /api/import/folder`
    - `POST /api/import/font`
