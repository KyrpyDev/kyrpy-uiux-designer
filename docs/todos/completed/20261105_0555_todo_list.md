- [x] **Task 1: Database Schema & Backend Services (`Trash`, `Copy/Move to Projects` with Cascading Sub-Items, `Empty Private Library`, Public Item Admin Guard, & `Scan list` Public Default Restoration)**
  - Add `deleted_at` and `deleted_by` columns to `paths`, `icons`, `buttons`, `elements`, `screens`, and `workflows` in `src/infrastructure/sqlite/schema.js` and `database.js` migrations.

  - Enforce **Admin / Superadmin Guard**: only `admin` or `superadmin` can trash or purge `public` (`visibility === 'public'` or `builtin`) items (`403 ForbiddenError`).
  - Implement **Copy to Projects / Move to Projects (`POST /api/library/copy-to-projects` & `POST /api/library/move-to-projects`)**:
    - Accepts `items: [{ type, id }]` and `projectIds: [number]` (multi-project target), setting target items to `visibility: 'project'` (private to each target project).
    - **Cascading Sub-Items**: When a `screen`, `element`, `button`, `icon`, or `workflow` is copied/moved to target project(s), recursively copy all referenced sub-items (`screen -> element -> button -> icon -> path`, including button menu icons, and `workflow -> screens -> sub-items`) into the target project's private sub-item libraries and re-point instance `refId`s to the project's copies.
    - Protect immutable default/built-in public items from being removed from the public default library during move (built-in public items are copied to target projects if moved, or rejected if non-admin tries to remove public items).
  - Implement **Empty Project's Private Library (`POST /api/projects/:id/empty-library`)**:
    - Empties (moves to Trash or purges) only project-private items (`visibility = 'project'`, `builtin = 0`) for a project (optionally filtered by item `type`).
    - Rejects attempts to empty the Default Public Library (`projectId === 1` public/default items or `visibility === 'public'`) with `403/409` because default libraries are immutable.
  - Implement **Trash Management API (`GET /api/trash`, `POST /api/trash/restore`, `DELETE /api/trash/purge`, `DELETE /api/trash/empty`)**.
  - Ensure `Scan list` (`key: 'scan-list'`) is recreated/restored in `src/data/designer.db` as a public default screen (`visibility = 'public'`, `builtin = 1`, `projectId = 1`, `deleted_at = NULL`) with its workflow links intact.
